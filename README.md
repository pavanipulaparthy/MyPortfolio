# Pavani Pulaparthi — Portfolio

A personal developer portfolio built with pure HTML, CSS, and JavaScript. No frameworks, no build tools — just drop it into GitHub Pages and it works.

## Live Demo

After deploying, your portfolio will be live at:
`https://<your-github-username>.github.io`

## How to Deploy on GitHub Pages (Step-by-Step)

### Step 1 — Create a GitHub repository
1. Go to [github.com](https://github.com) and sign in
2. Click the **+** icon (top right) &rarr; **New repository**
3. Name it exactly: `<your-username>.github.io`
   - Example: if your username is `pavanisatya`, name it `pavanisatya.github.io`
4. Set it to **Public**
5. Click **Create repository**

### Step 2 — Upload the file
1. In your new repo, click **Add file** &rarr; **Upload files**
2. Upload `index.html`
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to repo **Settings** &rarr; scroll to **Pages** (left sidebar)
2. Under **Source**, select **Deploy from a branch**
3. Choose **main** branch, **/ (root)** folder
4. Click **Save**

### Step 4 — Visit your live site
Wait ~1 minute, then visit:
`https://<your-username>.github.io`
